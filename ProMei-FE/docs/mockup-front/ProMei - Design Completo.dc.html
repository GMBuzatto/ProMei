ProMei — Design Completo (Proposta B)
Pacote de design equivalente a um arquivo Figma, fiel à Proposta B (espaçosa, amigável) e aos tokens de Design/DESIGN-SYSTEM.md + FIGMA-PALETAS.md. Tema padrão light; dark derivado dos mesmos Semantic Modes. Grid desktop 12 col / margens 32px; mobile ≥360px, alvos ≥44px. Todos os layouts assumem Auto Layout (flex/gap) e constraints fluidas no conteúdo.

7 · Decisões e pendências
Suposições adotadas (documentação ausente ou ambígua)
1. Logo: marca não definida — logotipo tipográfico "M" provisório.
2. Inadimplente = somente leitura (RF-23 deixa em aberto leitura vs bloqueio total); bloqueio total fica como variante do mesmo banner.
3. Criação de usuário sem e-mail: senha temporária exibida uma única vez, troca obrigatória no 1º acesso (deriva de RF-04).
4. Bloqueio de login: 15 min após 5 tentativas — RF-03 não define a duração.
5. Saída nunca deixa estoque negativo: erro de quantidade em D10/M10 (regra implícita em 04-regras).
6. Motivos de movimentação (Venda, Reposição, Perda/validade…) como lista fixa editável — não especificados.
7. Excluir item preserva histórico (soft delete) por causa de RNF-06.
8. Planos/preços/limites são exemplos fictícios (RF-21 define só os campos).
9. Tom de voz informal ("você") — não especificado na documentação.
10. Dark completo por derivação: telas dark não redesenhadas uma a uma; os Semantic Modes garantem o mapeamento 1:1 (seção 5 mostra o núcleo aplicado).
Pendências para validação
• Confirmar comportamento exato de empresa suspensa/inadimplente (leitura vs bloqueio).
• Definir marca/logo definitiva (07-stack aponta a pendência; paleta Blue já resolvida pelo DS).
• Validar campos do comprovante com contador (dados obrigatórios da "nota fria").
• Definir duração oficial do trial e régua de inadimplência.
• Lista oficial de motivos de movimentação e de unidades de medida.

Protótipo: por decisão do projeto, este pacote é estático (sem navegação clicável). Fluxos principais estão encadeados pela numeração: login → dashboard → saída 1→2 → comprovante.

Nomenclatura Figma: páginas Fundamentos / Componentes / Desktop / Mobile / Protótipo; frames "Desktop / Módulo / Tela — Estado" (ex.: "Desktop / Estoque / Saída — Etapa 1 · Erro"); componentes "Button / Primary / Default".
